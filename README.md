# Programmes 3e

Site HTML statique regroupant les présentations interactives :

- Français
- Histoire-Géographie-EMC
- Mathématiques
- Physique-Chimie
- SVT

## Mise en ligne avec GitHub Pages

1. Créer un dépôt GitHub, par exemple `programmes-3e`.
2. Envoyer tous les fichiers de ce dossier à la racine du dépôt.
3. Aller dans `Settings` > `Pages`.
4. Dans `Build and deployment`, choisir :
   - Source : `Deploy from a branch`
   - Branch : `main`
   - Folder : `/root`
5. Enregistrer.
6. Le lien sera disponible après quelques instants dans la page GitHub Pages.

Le fichier principal doit s'appeler `index.html`.
